# 📊 AI B2B经营分析助手

## 项目介绍

AI B2B经营分析助手是一款面向企业订单数据的智能经营分析系统。

系统通过 Python 数据处理流程完成订单数据清洗与指标计算，并结合大语言模型（LLM）自动生成经营诊断报告，帮助企业快速发现销售趋势、客户价值以及潜在经营风险。

---

## 项目背景

企业在日常经营过程中积累大量订单数据，但传统Excel分析方式存在：

- 数据处理效率低
- 指标计算依赖人工
- 难以及时发现业务问题

本项目尝试构建一个轻量级 AI 商业分析工具，实现从原始订单数据到经营洞察的自动化流程。

---

## 核心功能

### 1. 数据上传与清洗

支持上传企业订单Excel数据，并自动完成：

- 重复订单检测与处理
- 缺失字段检查
- 日期格式标准化
- 金额字段转换
- 客户主体识别
- 无效字段清理


### 2. 经营指标分析

自动计算核心经营指标：

- GMV（销售额）
- 订单数量
- 客户主体数量
- 产品SKU数量
- 平均客单价


### 3. 客户分析

从客户经营角度提供：

- TOP客户贡献分析
- 客户销售集中度分析
- 核心客户识别


### 4. 产品分析

分析产品销售表现：

- TOP产品排行
- 产品销售贡献
- 爆款产品识别


### 5. AI经营诊断

基于结构化分析结果，通过大语言模型生成：

- 当前经营情况
- 潜在风险
- 增长机会
- 优化建议
